1. What is Looper?

Looper is an automated coding assistant that works like having a tireless developer on your team. You describe a task in plain language, and Looper automatically:

Plan
→
Do
→
Check
→
Done!
  1. Plan — Analyzes the task and creates a step-by-step plan
  2. Do — Writes the actual code changes
  3. Check — Runs tests, linting, and type checking to verify the work

If the Check phase finds problems, Looper automatically loops back to fix them. This continues until everything passes.

For PMs & Planners: You don't need to write code. Just describe what you want in natural language, and Looper handles the rest. Use the Dashboard to manage tasks visually with a Kanban board.

2. Prerequisites

  • Claude CLI — The AI engine. Install Guide
  • Node.js 18+ — Required for the dashboard. Download
  • Git — For version control. Usually pre-installed on Mac/Linux.

3. Dashboard Quick Start

1

Install Dependencies

Open your terminal and run:

cd dashboard
npm install
2

Start the Dashboard

npm start

You'll see: Looper Dashboard running at http://localhost:3000

3

Open in Browser

Go to http://localhost:3000 in your web browser. You'll see the Kanban board.

Tip: If you have an Anthropic API key, you can set it before starting for better PM Agent performance:
ANTHROPIC_API_KEY=sk-ant-... npm start

4. Connecting a Repository

Before running loops, you need to tell Looper which code repository to work on.

Option A: Add a Local Repository

1

Go to Settings

Click Settings in the sidebar (gear icon), or click the repository indicator in the header.

2

Enter the Path

In the Repositories section, type the full path to your project folder (e.g., /home/user/my-project) and click Add Repository.

Option B: Connect GitHub

1

Create a GitHub Token

Go to GitHub Settings > Developer settings > Personal access tokens. Create a token with repo permission.

2

Connect in Settings

In Settings > GitHub Integration, paste your token and click Connect.

3

Browse & Clone

Enter your GitHub username or organization name, click Browse Repos, then click Clone & Add on the repository you want.

5. Creating Tasks

Manual Task Creation

1

Click "+ New Task"

On the Kanban board, click the + New Task button (or press N).

2

Fill in Details

Enter a title (e.g., "Add user authentication"), an optional description, set priority, and add labels.

PM Agent (AI-Powered Task Decomposition)

PM Agent takes a high-level description and automatically breaks it into smaller, actionable subtasks.

1

Switch to PM Agent Tab

In the New Task dialog, click the PM Agent tab.

2

Describe Your Goal

Write a high-level description of what you want to build. For example:
"Build a user registration system with email verification, password reset, and profile management"

3

Click "Decompose with AI"

PM Agent will analyze your description and generate 3-7 subtasks with titles, descriptions, and priorities.

4

Review & Add

Review the generated subtasks, uncheck any you don't want, then click Add All to Board.

6. Running a Loop

1

Click on a Task

Click any task card on the Kanban board to open the detail panel.

2

Click "Start Loop"

Click the Start Loop button. The task will move to "In Progress" automatically.

3

Watch Progress

The detail panel shows real-time agent logs. You'll see the AI planning, writing code, and running checks.

When the loop completes: If all checks pass, the task moves to Done. If something needs attention, it moves to Review.

7. Monitoring Progress

Loop History

Click Loop History in the sidebar to see all past loops. Click any row to see the full Plan-Do-Check timeline.

Analytics

Click Analytics to see statistics: pass rate, average iterations, task distribution across columns.

8. CLI Guide (Without Dashboard)

You can use Looper directly from the command line without the dashboard.

Install the Plugin

# Install from GitHub
claude plugin install vikyw89/looper

# Or install from a local checkout
claude plugin install /path/to/looper/plugins/looper

Run a Loop

# Start Claude Code
claude

# Then use the /loop command
> /loop "Add user authentication with JWT tokens"

The loop will automatically run Plan → Do → Check cycles until the task passes.

Understanding Output

During execution, you'll see:

  • Planner analyzing the codebase and creating a step-by-step plan
  • Doer writing code changes and committing them
  • Checker running tests, lint, typecheck, and build
  • A PASS or FAIL verdict from the Checker

Viewing Loop History via Git

All loop activity is tracked in git commits with special trailers:

# See all loop commits
git log --grep="Loop-Phase:"

# Each commit has trailers like:
# Loop-Phase: plan|do|check
# Loop-Iteration: 1
# Loop-Verdict: PASS (only on check commits)
Tip: The dashboard reads these same git commits to show Loop History, so you can switch between CLI and dashboard seamlessly.

10. Troubleshooting

PM Agent shows "Loading" forever
Check that Claude CLI is installed (which claude) or set ANTHROPIC_API_KEY environment variable before starting the dashboard.
Loop won't start
Make sure a repository is configured in Settings. The repository must be a valid git repository.
Dashboard won't load
Make sure Node.js is installed (node --version), then run npm install in the dashboard directory.
"Claude CLI not found" error
Install Claude CLI: https://docs.anthropic.com/en/docs/claude-code

11. Glossary

Loop
An automated Plan-Do-Check cycle that continues until the task passes all checks.
PDC (Plan-Do-Check)
The methodology Looper uses. Plan the work, Do the work, Check if it's correct.
Iteration
One complete cycle through Plan → Do → Check. A task may need multiple iterations.
Verdict
The result of a Check phase: PASS (all tests pass) or FAIL (needs fixes).
PM Agent
An AI assistant that breaks down high-level task descriptions into smaller, actionable subtasks.
Kanban Board
A visual board with columns (Backlog, Planning, In Progress, Review, Done) for managing tasks.
Claude CLI
The command-line interface for Claude AI, which powers Looper's code generation.

1. Looper란?

Looper는 팀에 지치지 않는 개발자가 있는 것과 같은 자동화된 코딩 어시스턴트입니다. 태스크를 일반 언어로 설명하면 Looper가 자동으로 처리합니다:

Plan (계획)
→
Do (실행)
→
Check (검증)
→
완료!
  1. Plan — 태스크를 분석하고 단계별 계획을 수립합니다
  2. Do — 실제 코드를 작성합니다
  3. Check — 테스트, 린팅, 타입 체크를 실행하여 작업을 검증합니다

Check 단계에서 문제가 발견되면 Looper가 자동으로 다시 루프를 돌며 수정합니다. 모든 검증을 통과할 때까지 계속됩니다.

PM & 기획자를 위한 안내: 코드를 직접 작성할 필요가 없습니다. 원하는 것을 자연어로 설명하면 Looper가 나머지를 처리합니다. 대시보드의 칸반 보드를 사용하여 태스크를 시각적으로 관리하세요.

2. 사전 요구사항

  • Claude CLI — AI 엔진. 설치 가이드
  • Node.js 18+ — 대시보드 실행에 필요. 다운로드
  • Git — 버전 관리용. Mac/Linux에는 보통 사전 설치되어 있습니다.

3. 대시보드 빠른 시작

1

의존성 설치

터미널을 열고 다음을 실행하세요:

cd dashboard
npm install
2

대시보드 시작

npm start

다음 메시지가 표시됩니다: Looper Dashboard running at http://localhost:3000

3

브라우저에서 열기

웹 브라우저에서 http://localhost:3000으로 이동합니다. 칸반 보드가 표시됩니다.

팁: Anthropic API 키가 있으면 시작 전에 설정하면 PM Agent 성능이 향상됩니다:
ANTHROPIC_API_KEY=sk-ant-... npm start

4. 저장소 연결

루프를 실행하기 전에 작업할 코드 저장소를 Looper에 알려줘야 합니다.

방법 A: 로컬 저장소 추가

1

설정으로 이동

사이드바에서 설정을 클릭하거나 헤더의 저장소 표시기를 클릭합니다.

2

경로 입력

저장소 섹션에서 프로젝트 폴더의 전체 경로를 입력하고 (예: /home/user/my-project) 저장소 추가를 클릭합니다.

방법 B: GitHub 연결

1

GitHub 토큰 생성

GitHub Settings > Developer settings > Personal access tokens에서 repo 권한이 있는 토큰을 생성합니다.

2

설정에서 연결

설정 > GitHub 연동에서 토큰을 붙여넣고 연결을 클릭합니다.

3

탐색 & 클론

GitHub 유저명이나 조직명을 입력하고 저장소 탐색을 클릭한 후, 원하는 저장소에서 클론 & 추가를 클릭합니다.

5. 태스크 생성

수동 태스크 생성

1

"+ 새 태스크" 클릭

칸반 보드에서 + 새 태스크 버튼을 클릭합니다 (또는 N 키를 누릅니다).

2

상세 정보 입력

제목 (예: "사용자 인증 추가"), 선택적으로 설명을 입력하고, 우선순위를 설정하고, 라벨을 추가합니다.

PM Agent (AI 기반 태스크 분해)

PM Agent는 상위 수준의 설명을 받아 자동으로 작은 실행 가능한 서브태스크로 분해합니다.

1

PM Agent 탭으로 전환

새 태스크 대화 상자에서 PM Agent 탭을 클릭합니다.

2

목표 설명

구현하고 싶은 것을 상위 수준으로 설명합니다. 예시:
"이메일 인증, 비밀번호 재설정, 프로필 관리를 포함한 사용자 등록 시스템 구축"

3

"AI로 분해하기" 클릭

PM Agent가 설명을 분석하고 제목, 설명, 우선순위가 포함된 3-7개의 서브태스크를 생성합니다.

4

검토 & 추가

생성된 서브태스크를 검토하고, 원하지 않는 것은 체크 해제한 후 전체 보드에 추가를 클릭합니다.

6. 루프 실행

1

태스크 클릭

칸반 보드에서 태스크 카드를 클릭하여 상세 패널을 엽니다.

2

"루프 시작" 클릭

루프 시작 버튼을 클릭합니다. 태스크가 자동으로 "진행 중"으로 이동합니다.

3

진행 상황 확인

상세 패널에서 실시간 에이전트 로그를 볼 수 있습니다. AI가 계획을 세우고, 코드를 작성하고, 검증하는 과정을 확인할 수 있습니다.

루프 완료 시: 모든 검증을 통과하면 태스크가 완료로 이동합니다. 주의가 필요하면 리뷰로 이동합니다.

7. 진행 상황 모니터링

루프 히스토리

사이드바에서 루프 히스토리를 클릭하면 모든 과거 루프를 볼 수 있습니다. 각 행을 클릭하면 전체 Plan-Do-Check 타임라인을 확인할 수 있습니다.

분석

분석을 클릭하면 통계를 볼 수 있습니다: 통과율, 평균 이터레이션 수, 컬럼별 태스크 분포.

칸반 보드

보드는 시각적 개요를 제공합니다. 태스크를 컬럼 간에 드래그하여 상태를 수동으로 업데이트할 수 있습니다.

8. CLI 가이드 (대시보드 없이)

대시보드 없이 명령줄에서 직접 Looper를 사용할 수 있습니다.

플러그인 설치

# GitHub에서 설치
claude plugin install vikyw89/looper

# 또는 로컬 체크아웃에서 설치
claude plugin install /path/to/looper/plugins/looper

루프 실행

# Claude Code 시작
claude

# /loop 명령어 사용
> /loop "JWT 토큰을 이용한 사용자 인증 추가"

루프가 자동으로 Plan → Do → Check 사이클을 태스크가 통과할 때까지 실행합니다.

출력 이해하기

  • Planner가 코드베이스를 분석하고 단계별 계획을 수립합니다
  • Doer가 코드 변경을 작성하고 커밋합니다
  • Checker가 테스트, 린트, 타입체크, 빌드를 실행합니다
  • Checker가 PASS 또는 FAIL 판정을 내립니다

Git을 통한 루프 히스토리 보기

# 모든 루프 커밋 보기
git log --grep="Loop-Phase:"

# 각 커밋에는 다음과 같은 트레일러가 있습니다:
# Loop-Phase: plan|do|check
# Loop-Iteration: 1
# Loop-Verdict: PASS (check 커밋에만)
팁: 대시보드는 이와 동일한 git 커밋을 읽어 루프 히스토리를 표시하므로, CLI와 대시보드를 원활하게 전환할 수 있습니다.

10. 문제 해결

PM Agent가 "로딩 중"에서 멈춤
Claude CLI가 설치되어 있는지 확인하세요 (which claude) 또는 대시보드 시작 전에 ANTHROPIC_API_KEY 환경변수를 설정하세요.
루프가 시작되지 않음
설정에서 저장소가 구성되어 있는지 확인하세요. 저장소는 유효한 git 저장소여야 합니다.
대시보드가 로드되지 않음
Node.js가 설치되어 있는지 확인하세요 (node --version), 그 다음 dashboard 디렉토리에서 npm install을 실행하세요.
"Claude CLI를 찾을 수 없음" 오류
Claude CLI를 설치하세요: https://docs.anthropic.com/en/docs/claude-code

11. 용어 설명

루프 (Loop)
모든 검증을 통과할 때까지 계속되는 자동화된 Plan-Do-Check 사이클입니다.
PDC (Plan-Do-Check)
Looper가 사용하는 방법론입니다. 작업을 계획하고, 실행하고, 올바른지 검증합니다.
이터레이션 (Iteration)
Plan → Do → Check를 한 번 완전히 거치는 것입니다. 태스크에 여러 이터레이션이 필요할 수 있습니다.
판정 (Verdict)
Check 단계의 결과: PASS (모든 테스트 통과) 또는 FAIL (수정 필요).
PM Agent
상위 수준 태스크 설명을 더 작고 실행 가능한 서브태스크로 분해하는 AI 어시스턴트입니다.
칸반 보드 (Kanban Board)
태스크를 관리하기 위한 컬럼 (백로그, 계획, 진행 중, 리뷰, 완료)이 있는 시각적 보드입니다.
Claude CLI
Looper의 코드 생성을 구동하는 Claude AI의 명령줄 인터페이스입니다.
